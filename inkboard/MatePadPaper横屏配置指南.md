# MatePad Paper 墨水屏信息台：横屏 + 全屏配置指南

> 适用对象：HUAWEI MatePad Paper（10.3 英寸，1872×1404，HarmonyOS 2）
> 目标：让 InkBoard 家庭信息台在墨水屏上以**横屏 + 全屏**常驻显示
> 更新日期：2026-09-01

---

## 一、先说结论：为什么不能直接横屏

华为官方（花粉俱乐部）对 MatePad Paper 横屏的明确回复：

> 市面上大部分应用未做墨水屏横屏适配，为了保证左右手握持体验，MatePad Paper 针对**部分系统应用仅支持 0° 与 180° 之间的旋转**。

翻译成白话：

| 项目 | 情况 |
|---|---|
| 自带浏览器、笔记、书城等**系统应用** | 只能竖屏 ↔ 倒竖屏（180° 翻转），**不支持 90° 横屏** |
| **第三方应用**（EinkBro 等） | 可被强制横屏 |

**关键提醒（来自花粉俱乐部用户实测）**：MatePad Paper 的重力传感器对方向的感知能力有限，**不能依赖系统的「自动旋转」**。正确做法是让应用**自己强制方向**，而不是等系统转。

---

## 二、推荐方案：EinkBro 浏览器

EinkBro 是专为墨水屏优化的开源浏览器（作者 Daniel Kao / plateaukao），自带的「旋转屏幕」按钮可以强制横屏，同时还有全屏、无动画、高对比黑白图标等墨水屏专属优化。这是最优选择。

### 2.1 下载与安装

**正规下载渠道（二选一）：**

1. **GitHub Releases（推荐）**
   - 地址：<https://github.com/plateaukao/einkbro/releases>
   - 下载最新版 APK（当前 v12.4.0），文件名类似 `einkbro-v12.4.0.apk`

2. **F-Droid**（开源应用商店，MatePad Paper 可先装 F-Droid 再装 EinkBro）
   - 在 F-Droid 里搜索 `EinkBro` 安装

**安装步骤：**
1. 把 APK 传到 MatePad Paper（微信/华为分享/数据线均可）
2. 首次安装会提示「未知来源应用」，到 **设置 → 安全 → 更多安全设置 → 外部来源应用下载** 里允许
3. 点击 APK 完成安装

> ⚠️ 请从 GitHub Releases 或 F-Droid 下载，不要从陌生第三方站下，避免捆绑包。

### 2.2 横屏 + 全屏配置（截图级步骤）

**第一步：打开信息台**
1. 打开 EinkBro，在地址栏输入信息台地址（以启动时打印的为准）：
   ```
   http://192.168.3.142:8765/
   ```
2. 等页面加载完成（显示时间、日期、待办、留言、日程）

**第二步：旋转到横屏**
1. 看底部工具栏，找到「**旋转屏幕 / Rotate**」按钮（图标是一个旋转箭头）
2. 点一下 → 页面强制切换为横屏
3. 若工具栏里没有这个按钮：**设置 → 工具栏定制**，把「旋转屏幕」图标拖进工具栏即可

> 📌 实测细节（花粉俱乐部用户反馈）：从横屏切回竖屏时，需要**先点旋转按钮、再把屏幕物理竖过来**才会转，这是墨水屏设备的正常行为，不是故障。

**第三步：进入全屏**
1. 工具栏点「**全屏 / Fullscreen**」按钮（图标是一个展开箭头）
2. 工具栏自动隐藏，信息台铺满整块墨水屏

**第四步（可选）：设置主页 / 防止误触**
- 把 `http://192.168.3.142:8765/` 设为 EinkBro 主页，下次打开直接进
- 全屏模式下，从屏幕边缘滑动可唤出 EinkBro 的悬浮导航球，用于退出全屏或刷新

### 2.3 备选方案：Rotation 类应用

如果不想换浏览器，也可以装一个 `Rotation` 方向的 app 强制横屏（花粉俱乐部用户实测「下个 rotation 就好了」）。但 EinkBro 一体化的旋转 + 全屏 + 墨水屏优化体验更好，优先推荐 EinkBro。

## 三、信息台在横屏下的表现

InkBoard 页面本身是**流式自适应**布局，无需改任何代码：

| 屏幕方向 | 基础字号单位 `--u` | 效果 |
|---|---|---|
| 竖屏 1404×1872 | 14.04px | 半幅组件（时间/日期）并排，整幅组件（待办/留言/日程）各自一行 |
| **横屏 1872×1404** | **18.72px** | 同样的排版，但**字号更大 33%**，内容更舒展，接近 4:3 宽屏比例 |

页面已监听屏幕旋转事件（`orientationchange`），旋转后会自动重排，无需手动刷新。

**更精细的做法（可选）**：管理端 `/admin` → 设置 → 尺寸预览，切到「按目标分辨率预览」，选 `1872×1404` 预设（或 `fitMode: fixed` 锁定），页面会精确缩放到该分辨率，在电脑上先调好版式再上屏。

## 四、墨水屏残影优化（重要）

墨水屏横屏时，数字时钟每秒刷新 + 屏幅变大，残影会比竖屏稍明显。信息台已内置以下优化：

| 机制 | 默认值 | 说明 |
|---|---|---|
| 整页全刷周期 | 300 秒 | 到点整页刷新，彻底清残影 |
| 全刷前闪白 | 开 | 先白屏 420ms 再重载，减轻残影 |
| 数据检查间隔 | 30 秒 | 内容真变了才重绘，无变化不动画面 |
| 秒级局部刷新 | 1 秒 | 仅时钟用，分钟/秒没变不写屏 |

**如果仍觉得时钟跳动残影烦**：手机/电脑打开管理端 `http://192.168.3.142:8765/admin` → 找到「时间」组件 → 把「显示秒」关掉，只保留时:分，残影会明显减轻。

## 六、一句话总结

> 系统自带浏览器锁竖屏 → 装 **EinkBro**（GitHub Releases / F-Droid）→ 工具栏点「旋转屏幕」强制横屏 → 点「全屏」铺满 → 打开 `http://192.168.3.142:8765/` 常驻显示。信息台已原生适配横屏，无需改代码；若嫌时钟残影，去管理端关掉「显示秒」即可。
