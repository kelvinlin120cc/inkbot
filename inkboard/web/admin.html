外部接入 Webhook

脚本、日历、Home Assistant 等可调用 POST /api/push 往信息台推待办 / 留言 / 日程。
curl -X POST http://<IP>:8765/api/push -H "Content-Type: application/json" -d "{\"op\":\"todo.add\",\"text\":\"买牛奶\",\"due\":\"2026-09-02\"}"
设了 Token 后需在 body 带 "token" 或请求头 X-InkBoard-Token。推送接口只放行写入类操作，改不了布局也删不了库。
